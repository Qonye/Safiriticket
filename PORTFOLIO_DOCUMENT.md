SafiriTicket CRM - Custom Business Management System

PROJECT OVERVIEW

SafiriTicket is a comprehensive custom-built CRM system designed specifically for travel and service businesses. This full-stack web application streamlines client management, quotation generation, invoicing, and financial tracking with multi-currency support and automated PDF generation.

TECHNOLOGY STACK

Backend
• Node.js with Express.js framework
• MongoDB with Mongoose ODM
• JWT authentication system
• Cloudinary integration for file management
• Railway deployment with persistent volume storage
• RESTful API architecture

Frontend
• Vanilla JavaScript (ES6+)
• Responsive CSS with mobile-first design
• Chart.js for data visualization
• HTML2PDF for document generation
• Real-time dashboard updates

CORE FEATURES

Client Management
• Complete client database with contact information
• Company and individual client support
• Activity tracking and communication history
• Search and filter capabilities

Quotation System
• Dynamic quotation creation with customizable items
• Multi-currency support (USD, EUR, GBP, KES, CAD, AUD)
• PDF generation and storage
• Status tracking (Pending, Accepted, Declined, Expired)
• Automatic expiration handling

Invoice Management
• Convert quotations to invoices seamlessly
• Multiple payment method configurations
• Partial payment tracking
• Automated status updates (Unpaid, Paid, Overdue)
• Sequential numbering system starting from INV-08463

Financial Dashboard

• Payment status visualization

Service Catalog

Organization Settings
